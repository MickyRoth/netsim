NetSim – Kurzanleitung

  • Gerät hinzufügen: aus der linken Leiste auf die Arbeitsfläche ziehen (oder einfach anklicken).
  • Verkabeln: mit gedrückter Maustaste von einem Anschluss (kleines Quadrat) zu einem freien Anschluss eines anderen Geräts ziehen. Grün = verbunden, rot = Port deaktiviert.
  • Konfigurieren: Doppelklick auf ein Gerät (oder Rechtsklick → Konfigurieren).
  • PC / Server: IP-Adresse, Subnetzmaske, Gateway oder DHCP. Ein Server kann zusätzlich als DHCP-Server dienen (Reiter „Dienste“).
  • Switch: VLANs anlegen und den Ports zuordnen (Access) oder Ports als Trunk zwischen Switches betreiben.
  • Router: 3 Schnittstellen mit IP/Maske, statische Routen z. B. 192.168.1.0/24 via 192.168.2.254.
  • Testen: im Terminal eines PCs/Servers ping 192.168.1.1, tracert 10.0.0.10, ipconfig; in der Router-CLI ping, show ip route, show ip interface brief.
  • Text: Werkzeug „Text“ aus der Leiste einfügen; danach Farbe, Schriftgröße und Normal/Fett/Kursiv wählen. Doppelklick auf einen Text öffnet den Editor erneut, Strg+Enter schließt ihn.
  • Ansicht: leere Fläche ziehen = verschieben, Mausrad = zoomen.
